└──────────────────────────────────────────────────────────────┘

1. OPEN ADMIN PANEL
   → Navigate to: admin/index.html
   → Already opened in your browser!

2. GO TO USERS SECTION
   → Click "Users" in the left sidebar
   → See table with all users

3. VIEW USER DETAILS
   → Click the eye icon (👁️) in Actions column
   → Modal opens with complete information

4. EXPLORE THE DATA
   → Review basic information
   → Check performance stats
   → See test history
   → View recent activity

5. TAKE ACTION
   → Click "Edit User" to modify details
   → Click "Close" to exit

📋 BASIC INFORMATION CARDS (6)
   1. Full Name           → User's complete name
   2. Email Address       → Contact email
   3. Selected Exam       → TNPSC exam type
   4. Preferred Language  → English or Tamil
   5. Account Status      → Active/Inactive
   6. Member Since        → Registration date

📊 PERFORMANCE STATISTICS (4 Metrics)
   1. Tests Taken         → Total completed tests
   2. Average Score       → Overall percentage
   3. Rank                → Current position
   4. Study Time          → Total hours spent

📝 RECENT TEST HISTORY (Table)
   → Test names
   → Scores out of 100
   → Test dates
   → Pass/Fail status with badges

🕐 RECENT ACTIVITY (Timeline)
   → Test completions
   → Test starts
   → Profile updates
   → With timestamps
