CSV Format Guide

Important:

You can upload questions in English only, Tamil only, or Both languages.
Leave columns empty if that language is not needed (e.g., leave Tamil columns empty for English-only questions).

Columns (13 total):
questionEn, questionTa, optionAEn, optionATa, optionBEn, optionBTa, optionCEn, optionCTa, optionDEn, optionDTa, correctAnswer, explanationEn, explanationTa

Example 1: Bilingual Question (English + Tamil)

questionEn,questionTa,optionAEn,optionATa,optionBEn,optionBTa,optionCEn,optionCTa,optionDEn,optionDTa,correctAnswer,explanationEn,explanationTa
"What is the capital?","தலைநகரம் எது?","Chennai","சென்னை","Mumbai","மும்பை","Delhi","டெல்லி","Kolkata","கொல்கத்தா","A","Chennai is capital","சென்னை தலைநகரம்"
