Quick Start Guide - Get Started in 60 Seconds!

🎉 Installation Complete!
Your Question Scraper is fully installed and ready to use. Follow the steps below to start importing questions.
1

Open Your Admin Panel

Navigate to your TNPSC Mock Test admin panel in your browser:

http://localhost/Mock_test/admin/

Make sure XAMPP Apache is running before accessing the panel.

📱 Open Admin Panel Now
2

Find "Question Scraper" in Sidebar

Look for the new menu item in the left sidebar:

📱 SIDEBAR MENU

Dashboard

Users

Exam Categories

Test Categories

Question Sessions

Add Question

⬇️ Question Scraper ⬅️ NEW!

Settings

Click on "Question Scraper" to open the scraper page.

3

Choose a Topic to Scrape

The scraper page includes example URLs at the bottom. Simply click on one:

💡 Example URLs (Click to Use):

🔗 சேர்த்து எழுதுதல் (Combining Words)
🔗 பிரித்து எழுதுதல் (Splitting Words)

Or paste your own URL from civilserviceaspirants.in website.

4

Click "Scrape Questions"

After selecting a URL, click the scrape button:

⬇️ Scrape Questions

You'll see a progress bar showing the scraping process:

60% - Parsing questions...

The scraper will automatically fetch all pages (typically 2-10 pages with 10-14 questions each).

5

Review & Save Questions

Once scraping is complete, you'll see all questions with:

  • Question text in Tamil
  • All four options (A, B, C, D)
  • Correct answer highlighted in green
  • Topic and category information

Now you have two options:

📥 Export JSON 💾 Save to Database
💡 Pro Tip: Export JSON first as a backup, then save to database!

⚠️ Common Issues & Solutions

Issue: "Failed to fetch content"

✓ Check internet connection
✓ Verify Apache is running in XAMPP
✓ Enable cURL in php.ini

Issue: "No questions found"

✓ Use the first page URL (-1.php)
✓ Test URL in browser first
✓ Check if website is accessible

Issue: Test page shows "PHP Backend: Error"

✓ Restart Apache in XAMPP
✓ Check php.ini for: extension=curl
✓ Review error logs
