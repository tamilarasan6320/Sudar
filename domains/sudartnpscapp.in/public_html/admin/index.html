Extract Questions from Website

Follow the steps below to extract questions from Civil Service Aspirants website

📋 Step-by-Step Guide

1 Find Your Exam URL

  1. Go to civilserviceaspirants.in
  2. Login with your credentials
  3. Navigate to the exam you want (e.g., "Group 4 - 2024 July")
  4. Open the first page of questions
  5. Copy the URL (should look like: ...Group-4-2024-july-1.php)

2 Count Total Pages

Look at the pagination at the bottom of the page.
If 200 questions with 10 per page = 20 pages
If 100 questions with 10 per page = 10 pages

3 Customize the Extraction Script

Change these 3 values in the script below:

💡 Example: If page 1 is "...Group-4-2024-july-1.php", copy everything before the "1"

4 Copy & Run the Script

Your customized extraction script:

⚠️ How to use:
  1. Click "Copy Script" button above
  2. Go to the question page on civilserviceaspirants.in
  3. Press F12 to open browser console
  4. Click the "Console" tab
  5. Paste the script and press Enter
  6. Wait for extraction to complete (1-2 minutes)
  7. JSON file will auto-download to your Downloads folder!

5 Upload the Extracted JSON

After the JSON file downloads:
1. Go to "Add Question" page
2. Click "Choose File" and select your downloaded JSON
3. Click "Upload JSON"
4. Done! ✅
