JSON Format Guide

Important:

Questions must have complete data in at least one language (English OR Tamil).
For questions with tables, use the table field with column_A and column_B arrays.

Example: Question with Table

{
  "totalQuestions": 1,
  "questions": [
    {
      "questionNumber": "2",
      "question": "வினைமுற்றுகளின் வகைகளோடு பொருத்துக:",
      "options": {
        "A": "3 1 4 2",
        "B": "3 4 1 2",
        "C": "4 3 2 1",
        "D": "4 1 2 3"
      },
      "correctAnswer": "B",
      "answerExplanation": "B. 3 4 1 2",
      "table": {
        "column_A": [
          { "key": "a", "value": "அழிந்தது தீமை" },
          { "key": "b", "value": "அற்றது பிறப்பு" },
          { "key": "c", "value": "நல்லது கை" },
          { "key": "d", "value": "குளிர்ந்தது நிலம்" }
        ],
        "column_B": [
          { "key": "1", "value": "சினைப்பெயர் கொண்டது" },
          { "key": "2", "value": "இடப்பெயர் கொண்டது" },
          { "key": "3", "value": "குணப்பெயர் கொண்டது" },
          { "key": "4", "value": "தொழிற்பெயர் கொண்டது" }
        ]
      }
    }
  ]
}
